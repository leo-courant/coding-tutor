# Coding Tutor

Your coding agent explains the implementation aloud while it builds it, and points at the code as it goes.

This extension owns the voice, the captions panel and the pointer. It needs the Coding Tutor agent tools (an MCP server) and `uv` installed for the local voice. See the project README for setup.

Commands: Sample voices, Open settings, Mute or unmute the voice, Skip what is being said, Open the latest transcript.
