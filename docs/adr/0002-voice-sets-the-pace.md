# The voice sets the pace; the engineer interrupts

The agent does not move on until it has finished saying the current piece, and it never waits for a "continue" between parts. The only planned stop is the route, where the tempo is agreed. After that the engineer steers by interrupting.

## Considered Options

- **A gate after every part** ("continue?"): rejected because pressing a button repeatedly is the stop-start rhythm this project exists to remove.
- **Agent runs at full speed with narration trailing behind**: rejected because the narration would describe code written minutes ago.
